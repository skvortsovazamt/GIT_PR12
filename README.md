## Описание программы

**TaskManager** — это простое консольное приложение для управления списком задач.
Программа позволяет *добавлять*, *удалять* и ~~забывать~~ отмечать задачи как выполненные. 😉

Эти инструкции предоставят вам копию проекта и помогут запустить на вашем локальном компьютере для разработки и тестирования.

### Необходимые условия

Для установки программного обеспечения вам потребуется:

- Python **3.10+**
- pip (менеджер пакетов)
- Git

```
python --version
pip --version
git --version
```

### Установка

Пошаговая серия примеров, которые говорят, что вы должны запустить.

**Шаг 1.** Клонируйте репозиторий:

```
git clone https://github.com/username/taskmanager.git
cd taskmanager
```

**Шаг 2.** Создайте виртуальное окружение и активируйте его:

```
python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # Linux / macOS
```

**Шаг 3.** Установите зависимости:

```
pip install -r requirements.txt
```

**Шаг 4.** Запустите программу:

```
python main.py
```

Завершите пример получением некоторых данных о системе или использования их для небольшой демонстрации:

```
python main.py --version
```

## Использование

Функция `add_task()` добавляет новую задачу:

```python
from taskmanager import add_task

add_task("Подготовить README.md")
print("Задача добавлена ✅")
```
